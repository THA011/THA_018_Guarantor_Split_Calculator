# Guarantor Allocation Calculator

Welcome to the Guarantor Allocation Calculator project! This application is designed to help users calculate the allocation of guarantees among multiple guarantors based on user-defined parameters. It features a user-friendly interface, dynamic results display, and smooth animations to enhance the overall experience.

## Features

- **Main Calculator Interface**: Users can input loan amounts and guarantor deposits to compute allocations.
- **Dynamic Results Display**: Results are updated in real-time, showing both equal capped and proportional distributions.
- **Input Validation**: Ensures that all user inputs are correctly formatted and valid.
- **Dashboard**: Users can view a summary of previous calculations and revisit their inputs and results.
- **Animations**: Smooth transitions and effects enhance user interaction throughout the application.

## Project Structure

The project is organized into several key directories:

- **src/components**: Contains React components for the calculator, results display, and input form.
- **src/pages**: Includes the main pages of the application, such as Home and Dashboard.
- **src/services**: Houses the core logic for allocation calculations and data processing.
- **src/types**: Defines TypeScript interfaces and types for type safety.
- **src/styles**: Contains CSS files for styling the application, including main styles and animations.
- **src/utils**: Utility functions for input validation and data formatting.

## Installation

To get started with the Guarantor Allocation Calculator, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd guarantor-allocation-calculator
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.

## Usage

Once the application is running, you can:

- Enter the total loan amount and the deposits of each guarantor in the input form.
- Click on the calculate button to see the allocation results.
- Navigate to the dashboard to view previous calculations.
