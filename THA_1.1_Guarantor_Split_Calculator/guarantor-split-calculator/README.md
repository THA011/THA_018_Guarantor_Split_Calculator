# Guarantor Split Calculator

This project is a React application designed to help users calculate the split of guarantor responsibilities. It provides a user-friendly interface for inputting data and displays the results of the calculations.

- [Installation](#installation)
- [Usage](#usage)
- [Components](#components)
- [Contributing](#contributing)
- [License](#license)

## Installation

To get started with the Guarantor Split Calculator, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/guarantor-split-calculator.git
   ```
2. Navigate to the project directory:
   ```
   cd guarantor-split-calculator
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the application in development mode, use the following command:
```
npm start
```
This will start the development server and open the application in your default web browser.

## Components

The application consists of the following main components:

- **Calculator**: Handles the main logic of the guarantor split calculation, including state management and event handling.
- **InputForm**: Provides input fields for users to enter necessary data for the calculation.
- **ResultsDisplay**: Displays the results of the calculation based on the input provided by the user.
- **Header**: Renders the header section of the application, including the title and navigation links.
- **Home**: Serves as the main landing page of the application, incorporating the `Calculator` and `Header` components.
- **About**: Provides information about the application and its purpose.
